تطبيق متابعة المحاضرات

رفع التطبيق أول مرة:
1) افتح app.netlify.com/drop واسحب المجلد كله (مش الملف المضغوط) فيها.
2) سجّل بحساب مجاني عشان الموقع يفضل شغال.
3) افتح اللينك من الموبايل ثم:
   أندرويد (كروم): قايمة النقط التلاتة ثم "تثبيت التطبيق".
   أيفون (سفاري): زرار المشاركة ثم "إضافة إلى الشاشة الرئيسية".

تحديث التطبيق بعد أي تعديل:
1) فك ضغط النسخة الجديدة.
2) في Netlify افتح الموقع ثم Deploys ثم اسحب المجلد الجديد (نفس اللينك بيفضل زي ما هو).
3) على الموبايل افتح التطبيق وانت متصل بالإنترنت: بيجيب النسخة الجديدة لوحده.

المزامنة مع جوجل (اختيارية):
- بتحفظ علامات المذاكرة والمراجعة في Google Drive بتاع كل شخص (مكان مخفي خاص بالتطبيق بس).
- بتشتغل بعد ما تعمل Client ID وتبعته للمساعد عشان يتحط في التطبيق:
  1) console.cloud.google.com ثم مشروع جديد.
  2) APIs & Services ثم Library ثم Google Drive API ثم Enable.
  3) OAuth consent screen: النوع External، اسم التطبيق وإيميلك، وفي Scopes ضيف drive.appdata، ثم Publish app.
  4) Credentials ثم Create credentials ثم OAuth client ID ثم Web application، وفي Authorized JavaScript origins حط لينك موقعك على Netlify (من غير / في الآخر).
  5) انسخ الـ Client ID وابعته.
- لو الـ Client ID فاضي، قسم المزامنة مش بيظهر.

ملاحظات:
- لازم HTTPS عشان التثبيت وتحديد الموقع والمزامنة.
- التقدم بيتحفظ في المتصفح على اللينك اللي فتحته منه.
